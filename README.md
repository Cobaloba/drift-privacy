# Drift — privacy policy

The privacy policy for the Android game **Drift** (`com.conor.drift`),
published at <https://cobaloba.github.io/drift-privacy/>.

This repository exists only to host that page publicly, as required by Google
AdMob and the Google Play Console. The game itself lives in a private repo;
the source of this page is kept there under `tools/privacy/` and copied here.
